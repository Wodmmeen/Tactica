# TACTICA — Тактическое снаряжение и EDC

Магазин тактического снаряжения: ножи, фонари, мультитулы, страйкбол, аксессуары.  
Портфолио-проект: кастомный роутер, фильтры, корзина, сравнение, EDC-конструктор, квиз-рекомендации.

## Стек

- **PHP 8.2** — без фреймворка, свой роутер
- **Nginx** + PHP-FPM
- **SCSS** → CSS (токены, компоненты, лейаут)
- **Vanilla JS** — корзина, сравнение, избранное, квиз, конструктор
- **localStorage** — состояние корзины, сравнения, избранного, заказов

## Фичи

- Каталог с фильтрами (сталь, бренд, вес, цена, наличие) и сортировкой
- Карточка товара с характеристиками и похожими
- Корзина: добавление, количество, удаление, сумма
- Сравнение: side-by-side таблица до 4 товаров
- EDC-конструктор: выбор по категориям, сумма + вес набора
- Квиз-рекомендации по сценарию (EDC / Airsoft / Urban) + бюджет
- Блог: 6 статей
- Checkout: форма + сохранение заказа в localStorage
- Мои заказы: история из localStorage
- Избранное: объекты в localStorage, работают на всех страницах
- 404, статические страницы (о нас, доставка, гарантия, контакты)
- Мобильное меню, scroll-reveal
